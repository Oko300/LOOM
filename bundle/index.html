Loom needs the FlowDev VS Code extension to access your project files and build persistent memory of your project.

One-time setup

1
Get a free token at flowdev.onrender.com/request
2
Install FlowDev MCP from the VS Code Extension Marketplace
3
Paste your token in the FlowDev sidebar in VS Code and click Connect
4
Add your FlowDev token to Loom's settings, then click Check Connection below

Your token is stored securely in Anna's credential vault and never shared.
